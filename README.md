# Neural-Detector
Hybrid ai text detector:perplexity,neural network,web search.Beautiful UI
## About

This is a hybrid neural network detector that combines multiple analysis methods into a single ensemble. It uses adaptive triggers and has a clean animated interface.

**Status:** This is a research project. I'm still in school and don't have much time to keep developing and learning Python. But I can keep this idea going - bigger, better, cooler - depending on how interested the audience is. I'll add features and change things if there's demand.

This is more of an experimental/research product than a finished tool. If projects like this are interesting to people, if there's something to strive for, I'll keep working on it.

**The question:** does it make sense if the program doesn't give 100% accuracy? Is it worth the time?
